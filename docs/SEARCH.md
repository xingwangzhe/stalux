# 搜索

Stalux 在构建后自动生成 Pagefind 全文索引，并额外生成分片 CJK 子串索引。搜索弹窗与 WebMCP 共用这两套数据。

## 索引内容

| 字段 | 是否参与检索 |
| --- | --- |
| 标题 | 是 |
| 摘要（`desc`） | 是 |
| 标签 | 是 |
| 分类 | 是 |
| 正文 | 是（Pagefind） |
| `searchKeywords` | 是，来自文章 frontmatter 的可选字符串数组 |

```yaml title="文章 frontmatter 示例"
searchKeywords: [别名, 缩写]
```

`searchKeywords` 默认空数组。这些关键词会公开写入 HTML 和静态搜索索引，**不应用于保存私密内容**。

## CJK 查询增强

| 行为 | 说明 |
| --- | --- |
| 未加引号的中 / 日 / 韩查询 | 补充连续子串命中，支持单字 |
| 规范化 | NFKC 全角 / 半角统一 |
| 多词 | 支持空格分开的多个词 |
| 排序 | 连续标题匹配优先 |
| 候选校验 | 候选必须通过原文核对；原生结果保留并去重 |
| 引号查询 | 保留 Pagefind 原生语义 |
| 活动筛选 | 保留 Pagefind 原生语义 |
| 不提供 | 自动简繁转换、拼音、错别字、语义搜索 |

## 加载与降级

| 情况 | 行为 |
| --- | --- |
| 索引加载 | 按需加载，无外部查询服务，不新增遥测 |
| 增强索引失败 | 退回 Pagefind |
| 资源加载失败 | 可重试 |
| 无 JavaScript | 保留 `<noscript>` 样式回退 |

## 首屏 CSS

Pagefind 搜索弹窗样式单独输出为带哈希的静态文件，以 `prefetch` 提示浏览器提前获取；打开搜索时才作为样式表启用，并等待加载完成后显示弹窗。它不阻塞正文首屏，也不依赖搜索 JavaScript 动态生成 CSS 文件。

## 搜索弹窗与 WebMCP

搜索弹窗和 WebMCP 的 `stalux_search_posts` 共享检索能力，但输出不同：弹窗返回页面结果，WebMCP 返回分页元信息与摘要。工具细节见 [WebMCP](./WEBMCP.md)。
