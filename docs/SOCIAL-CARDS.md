# 文章分享卡片

文章分享图按以下优先级选择，`cover` 仍用于站内文章列表：

| 优先级 | 文章字段 | 分享行为 |
| --- | --- | --- |
| 1 | `og:image` | 非空时直接使用指定图片，不加工；支持 HTTP(S)、协议相对 URL 和站点根路径，建议 PNG / JPEG、1200×630 |
| 2 | `cover` | 将封面裁切为右侧彩色图片栏，放入黑白标题卡片 |
| 3 | 无封面或封面不可用 | 生成纯黑白标题卡片，不再用头像充当文章分享封面 |

```yaml title="文章分享图配置"
cover: /images/article-cover.webp
og:image: /images/custom-social-card.png
```

`og:image` 可省略或留空；不需要修改已有文章。

## 卡片内容

黑白卡片包含以下信息，封面区域保持原图彩色：

| 位置 | 内容 |
| --- | --- |
| 左上 | 网站名称 |
| 右上 | 文章分类 `category` |
| 主标题 | 文章标题，最多三行，超出省略 |
| 标题下方 | 文章 `tags`，形如 `#Astro   #性能` |
| 标签下方 | 文章链接，去掉协议头的完整路径，如 `xingwangzhe.fun/posts/abc123/` |
| 左下 | 网站链接（域名） |
| 右下 | 作者与按站点时区显示的日期 |

正文不显示摘要、强调色、渐变或装饰图形；除封面外全部为黑、白和中性灰。

## 输出

| 项 | 说明 |
| --- | --- |
| 生成位置 | 有封面：`/og/<元数据哈希>.jpg`；无封面：`/og/<元数据哈希>.png` |
| 引用 | 静态 HTML 的 `og:image`、`twitter:image` 和 BlogPosting `image` 指向同一绝对地址 |
| 尺寸 | 1200×630 |
| 类型 | 有封面为 `image/jpeg`，无封面为 `image/png` |
| Twitter | 文章使用 `summary_large_image` |
| 回退格式 | 只生成一张图，不再追加第二种格式 |
| JPEG 质量 | 60；纯文字 PNG 由渲染器直接输出，体积通常约 20–30 KB |

## 渲染

图片由 `@takumi-rs/core` 在构建期本地渲染，使用主题自带的 LXGW WenKai 字体，不向浏览器增加渲染器 JS，也不调用远程制图服务。

| 项 | 规则 |
| --- | --- |
| 本地封面 | 从最终 `publicDir` 读取 |
| 远程封面 | 从构建机请求原 URL，单次最长 8 秒、最多 8 MiB，字节缓存 24 小时 |
| 封面处理 | 由 Takumi 按 440×630 裁切并保留彩色，不写入 SVG 或额外图片文件 |
| 不可读 / 无法解码 | 警告并回退纯黑白标题卡片 |
| 显式 `og:image` | 由社交平台自行抓取，不在构建时转码；请确保公开可访问且内容为图片 |
| 缓存 | 生成结果保存在 Astro 缓存目录的 `stalux-social-cards/` 下，仍会将图片写入本次静态输出 |
| 渲染缓存 | 同一份卡片数据、字体和封面字节只渲染一次；构建前半段命中缓存时不裁切封面 |

社交平台有自己的预览缓存，页面部署成功不代表已有分享卡片立即刷新。
