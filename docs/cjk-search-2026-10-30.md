# CJK 搜索增强与独立消费项目验收（2026-10-30）

## 问题与实现

myblog 的目标文章《解决国外人机验证不显示问题》（37f315ff）在原生 Pagefind 1.5.2 中搜“人机验证”未命中，搜索完整标题也返回 0 条。当前增强保留 Pagefind 正常搜索，在构建时另生成 CJK 单字和相邻双字倒排分片；浏览器将原查询、NFKC 规范化查询和经过原文连续性核对的候选合并，按结果 id 去重，标题连续匹配优先。所有原生结果保留。

标题、摘要、标签、分类和可选 searchKeywords 进入索引；关键词公开输出，不能保存秘密。原生分词仍承担常规匹配；引号和活动筛选保持原生语义。补充索引资源加载失败时退回 Pagefind，失败项可重试。搜索弹窗经公开 bundlePath/createInstance 接口接入，WebMCP 读取同一增强模块，不修改 Component UI 私有字段，不引入远端查询服务。

## 能力边界

本轮提供 CJK 字符连续子串召回与结果合并，不等于日文读音、韩文形态分析、拼音、自动简繁体转换、错别字纠正或语义搜索。日文/韩文字符的 gram 生成有单测；真实 myblog 的文章验收主要是中文，不能宣称完成了母语日文和韩文语料质量评估。
