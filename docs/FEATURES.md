# 功能行为

本文记录 Stalux 开箱即用的运行时行为。大多数功能无需配置；需要开关的部分会给出对应配置入口。

## 导航与页脚

| 功能 | 行为 |
| --- | --- |
| 顶部导航 | 吸附在视口顶部；向下滚动超过 24px 后显示模糊玻璃背景，返回顶部恢复透明 |
| 手机菜单 | 滚动后菜单按钮显示同样的玻璃背景；抽屉展开时隐藏按钮，关闭后恢复 |
| 回到顶部 | 所有 HTML 路由页脚内置圆形按钮，滚动 240px 后显示，点击平滑回顶；遵循减少动画设置，打印时隐藏，不遮挡正文、不改变页面宽度和居中布局 |
| 一言卡片 | 日期可用于定位，正文及来源链接可独立访问 |
| 页脚徽章 | 构建期输出为带内容哈希的独立 SVG；折叠分组使用原生懒加载，展开和禁用 JavaScript 时仍可显示 |

## 首页打字机

由 Stalux 自有组件提供，读取 `stalux/config/typetexts.yml` 的 `items` 字符串列表，无需新增配置。

| 行为 | 默认值 / 说明 |
| --- | --- |
| 输入速度 | 100ms / 字素 |
| 删除速度 | 33ms / 字素 |
| 完整停留 | 1500ms |
| 清空后等待 | 500ms |
| 视口外 / 后台 | 暂停 |
| 软导航 | 清理并重新初始化 |
| 减少动画 | 整句轮播，隐藏光标 |
| 禁用 JavaScript | 显示首句；屏幕阅读器和打印输出完整列表 |

首页打字区域按完整文案预留最大换行高度，文本起点固定；时钟预留行高并使用等宽数字，避免字体换入或页面高度变化引起布局跳位。

## 文章图片与图注

独占段落的图片 `![图片说明](url)` 会在构建期通过 satteri HAST 自动生成 `figure` 和 `figcaption`，在图片下方显示居中的灰色小字。保留图片 `alt` 和 PhotoSwipe 灯箱，无需配置或浏览器脚本。

| 情况 | 处理 |
| --- | --- |
| 空描述 | 不生成图注 |
| 行内图片 | 不生成图注 |
| 同段多图 | 不生成图注 |
| 已有 `figure` | 不重复生成 |
| 图注内容 | 按纯文本输出，特殊字符自动转义 |

外部图片可在 Markdown 标题里声明尺寸：

```md
![说明](https://example.com/a.webp "1150x439")
```

构建期会转成 `width` / `height` 并移除提示性 `title`，PhotoSwipe 同时拿到 `data-pswp-width/height`；不写尺寸声明时保持原行为。

PhotoSwipe 灯箱懒加载，首次点击才拉取 photoswipe 资源，并在初始化完成后立即打开被点击的图片；软导航后会重置状态，下一次点击重新初始化。

## 代码块主题

代码块默认固定为 `dark-plus` 暗色主题，不跟随系统明暗偏好，也不生成主题切换选择器。需要自定义时，通过 `expressiveCode` 显式覆盖：

```ts
stalux({
    expressiveCode: {
        themes: ["dark-plus"],
        useDarkModeMediaQuery: false,
        themeCssSelector: false,
    },
});
```

此行为只改变构建生成的代码样式，不增加遥测。

## 归档、标签与分类

| 区域 | 行为 |
| --- | --- |
| 归档 | 透明背景的单列年 / 月时间线，所有文章始终展开；月份首次进入视口时以 280ms 轻微位移和淡入，使用浏览器原生 API，无新增依赖 |
| 归档降级 | 减少动画、打印、缺少浏览器 API 及禁用 JavaScript 时保持完整静态列表；手机端日期位于标题上方，长标题自然换行 |
| 文章标题悬停 | 只保留一条下划线；鼠标悬停或键盘聚焦时在右侧预览原有 `desc`，靠近视口边缘时移到下方；空摘要不显示预览，触屏仍直接打开文章 |
| 摘要预览层 | 使用浏览器顶层浮层，不受父容器裁剪及普通层级遮挡；不支持时使用高层级回退 |
| 标签云 | 桌面标签云进入视口附近后才动态加载；切换移动布局、离屏或页面隐藏时销毁实例以停止动画调度，重新可见后恢复；标签点击使用与普通站内链接相同的 Swup 导航 |
| 分类 / 标签页 | 按组 / 按卡片保留静态 HTML 并跳过离屏渲染 |

## 页面布局

| 项 | 规则 |
| --- | --- |
| 文章页 | 宽屏使用左右各 280px 侧栏，间距 24px，整体最多 1544px，外侧内边距 16px；小于 1600px 时收起两侧栏，改为最大 936px 单栏 |
| 正文 / 摘要卡 | 最大宽度 840px |
| 摘要 | 读取文章原有 `desc`，为空时不显示 |
| Markdown 引用块 | 显示为提示卡，无需新增配置或修改文章语法 |
| 友情链接 | 列表最大宽度 1600px，左右内边距各 16px；卡片填满网格列，随屏幕宽度使用一至五列布局 |
| 宽内容 | 代码、表格、公式与 Mermaid 在局部滚动 |

## 友链与随机文章

友链图标只在滚动到附近时请求（400px 预取边距），不会因为浏览器原生 lazy 的大预取窗口把整页第三方头像都拉下来；加载失败保留占位圆盘，文字信息不受影响。

随机文章侧栏等到接近视口才请求索引，不在首屏加载。

## 评论（Waline）

Waline 在接近视口时加载，在 Astro 换页前销毁，在新页面重新挂载；评论资源加载失败可点击重新加载页面，重建浏览器模块状态。评论正文与输入控件使用系统字体，代码使用系统等宽字体，避免继承构建期 LXGW WenKai 逐页字体子集。配置见 [配置说明](./CONFIGURATION.md#评论commentyml)。

## 软导航与动效

软导航由 Swup 负责。Astro 渲染静态文档，浏览器按路由替换主内容或文章、分类详情片段，导航、页脚、滚动 sentinel 和背景继续保留原 DOM。插件职责与脚本执行规则见 [生命周期与静态接口](./RUNTIME.md#swup-导航与插件边界)。

| 场景 | 动效 |
| --- | --- |
| 进入阅读 | 最多纵向 6px |
| 上一篇 / 下一篇 | 水平 8px |
| 普通阅读替换 | 纵向 4px |
| 同维度筛选 | 水平 6px |
| 跨分类 / 标签维度 | 中性淡入 |
| 桌面 | 入场 100–180ms，退场 80ms |
| 手机 | 统一 120ms 纯淡入 |
| 长正文 / 长列表 | 保持直接可读，不整体位移或隐藏 |
| 历史恢复 / 减少动态 / 原生手势 / 同页锚点 | 不重播页面动画 |

完整模块清单、降级规则与生命周期见 [模块与视图过渡](./MOTION.md) 和 [生命周期与静态接口](./RUNTIME.md)。

## 背景

内置 42 张背景，默认使用预生成的深色底 WebP（quality 80），保持原分辨率，减少透明度边缘带来的首访流量。

| 情况 | 行为 |
| --- | --- |
| CSS 自定义底色 | 使用原透明 WebP |
| SVG 原图 | 继续保留 |
| 背景尺寸 | 原 SVG 只有 `viewBox`，其 auto 尺寸等价于 `contain`；内置 WebP 显式沿用 `contain`，自定义背景 URL 保持原有尺寸 |
| 增删图片 | 修改原图后运行 `bun run backgrounds:build` 重新生成实体资源；消费项目构建只复制资源，不重复栅格化 |
| 运行时 | 每个完整文档随机选择并异步解码一次，首次从稳定暗底用 200ms 淡显；同一 Swup 会话的软导航保持这张背景，不再重选、重复解码或交叉淡入 |
| 减少动画 | 直接显示 |
| saveData | 保留暗底且不请求装饰 SVG |
| 自定义 | `window.__STALUX_BG_URLS__` 继续生效；慢加载或解码失败不会阻塞阅读 |

## 国际化

界面文案随 `site.yml` 的 `lang` 切换，内置英文 / 中文。WebMCP 工具描述也会跟随站点语言。
