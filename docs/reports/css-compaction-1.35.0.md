## 标准及运行环境限制

Lightning CSS 目标为 Chrome 154、Firefox 157、Safari 26.6；现代 `rgb()`、逻辑属性、`clip-path` 等依据 [MDN CSS](https://developer.mozilla.org/en-US/docs/Web/CSS)核实。移除自有规则的废弃 `clip`、`word-wrap`、非标准字体平滑及冗余前缀；仍需要的多行截断和第三方兼容规则保留。

实际系统 Chrome 154 已运行，Firefox 可用版本为 156，未运行目标 Firefox 157。WebKit 26.6 下载遇到 CDN 连接重置和停滞，未完成 Safari 实机验证。此处不能声称三个最新稳定浏览器全部验收完成。
