## 闲来无事，想起了这个游戏

考虑到我现在使用 **Ubuntu**，玩 **Steam** 上绝大一部分游戏都要过一层**兼容层**，所以我准备玩一些老游戏，翻了翻库，发现 POSTAL 2，还有 Half life 还没玩通关，抉择一下，先玩 POSTAL 2。

### 游戏简介

| 项目         | 信息                       |
| ------------ | -------------------------- |
| **原名**     | POSTAL 2                   |
| **官方译名** | 夺命邮差2                  |
| **常用译名** | 夺命邮差2、喋血街头2       |
| **类型**     | 第一人称射击游戏、动作游戏 |
| **开发商**   | Running With Scissors      |
| **发行日期** | 2003年4月13日              |

来源：[萌娘百科](https://mzh.moegirl.org.cn/%E5%A4%BA%E5%91%BD%E9%82%AE%E5%B7%AE2) | [百度百科](https://baike.baidu.com/item/%E5%96%8B%E8%A1%80%E8%A1%97%E5%A4%B42?fromtitle=%E5%A4%BA%E5%91%BD%E9%82%AE%E5%B7%AE2&fromid=23716109&fromModule=lemma_search-box)

《夺命邮差2》是一款极具争议性的第一人称射击游戏。游戏设计为在街头玩家可以伤害每一个人，以其极端暴力和黑色幽默而闻名。玩家在游戏中扮演一名叫做 **Dude** 的人，在一个充满荒诞和暴力的美国小镇 Paradise 中度过平凡的一周。

游戏的主要内容围绕着 Dude 的日常生活展开，玩家需要完成一系列看似平常的任务，如购买牛奶、归还图书馆的书籍、取薪水等。然而，这些`简单`的任务总是会演变成血腥的暴力事件。

**主要角色**

- **Dude**：游戏主角，一个运气极差的邮差，连续五天(算上DLC应该是七天)遇到各种倒霉事。配音：Rick Hunter（英文）、Mingway Yang（中文）
- **Vince**：游戏中 "RWS" 这家游戏公司的角色

### 游戏结构

游戏采用**开放世界**设计（周一到周五）(DLC还有周末两天)，玩家可以自由探索 Paradise 小镇。到了周末则变为**线性关卡**设计，这也是稍微感到不适应的地方。

### 印象深刻

任务详细信息：[萌娘百科剧情详解](https://mzh.moegirl.org.cn/%E5%A4%BA%E5%91%BD%E9%82%AE%E5%B7%AE2)

游戏开始时，镜头从街道开始转到车房，期间的中文配音，有点怪，尤其还是掺杂了各种诡异的污言秽语，很难想象那是一个2003年发行，2018年更新中配的游戏，疑似有点超现实主义了。尽管第一印象已经很烂了，一些剧情也是极其之烂，但还是莫名戳中笑点

周一的那个任务，去游戏公司取💰，公司门口有一个反游戏团体，口号喊着“坏游戏让人疯！”，当时就逗笑了，后来拿💰之后，那个团体就冲了进来，与它们斗争的经历，让我感受到了这个游戏射击体验是多么的烂！尤其是霰弹枪，是真得贴着脸才能过去

周二那个请愿书应该是~~最困难的~~了，找了好多人才签请愿书，还有周四的获取`Krotchy`玩偶，形状有点**特征突出**，最简单的应该是周五的治病任务了，唯一的问题就是那个口太小，🐦不进去，泚了一地把机器也泚了。

最震撼的应该是周五的那个Dave舅舅的生日任务了，有战地的感觉，强行突入包围，过程极其艰难，后来找了狙击枪发现简单了许多。

周末两天就开始大便了，从原来的开放世界变成了线性关卡，有点不适应，尤其是还没地图，虽然周一到周五的地图也是一团糟，但是勉强也能看，周末虽然是线性的，但有时候也会迷路。

周六屠宰🐮的任务还是有点意思,🐮🐮冲击让我重开好几次,而且没想到僵尸🐮也是需要爆头才能彻底消灭

周日极其之难，进入恐怖分子大本营，勇闯军事基地，以至于我得开挂才勉强通关，那个最终的奇怪BOSS太逆天了，开挂都得打半天

### 深刻讽刺

游戏中有很多对美国社会的讽刺。这些讽刺元素包括：

**社会议题讽刺**：

- **反游戏团体**：游戏中出现抗议暴力游戏的团体
- **恐怖主义**：在教堂那个任务，💥极尽讽刺
- **枪支暴力**：对美国枪支文化的黑色幽默式批判
- **政府腐败**：怀疑那个镇长有股份，可以通过交💰来消通缉
- **性少数群体**：🐦墓之后被当作男M

**黑色幽默特色**：
RWS在采访中所说：

“游戏的唯一乐趣就在于尽可能地去伤害每一个人。”

“这款游戏不仅仅意味着暴力。暴力本身并不有趣。粗俗本身也不有趣。我们需要在这些原素和其他可以产生有趣的黑色幽默的元素之间找到一个平衡点。”

**争议性**：
正是这些极端的讽刺手法和恶心元素让游戏备受争议，在多个国家被禁售。

| **瑞典** | 禁售 | 有家长因担心游戏对儿童产生不良影响，将《Postal 2》告上法庭，致其在瑞典被禁售 |

### 技术特点

**游戏引擎**：基于虚幻引擎开发 (很难相信对吧？但还真是虚幻引擎)

**中文配音**：2018年更新添加了中文配音，虽然质量参差不齐但极大地增加了游戏的趣味性(考证了一下，似乎2017年就有了中文配音？)
