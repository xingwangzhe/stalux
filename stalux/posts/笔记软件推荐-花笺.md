## 🪷 花笺是什么

简单来说，花笺是一个**本地桌面便签工具**。不是那种花里胡哨的全功能笔记软件，而是回归到"便签"的本质：**随时记、随时看、随时走**。

| 维度           | 花笺                                                                  |
| -------------- | --------------------------------------------------------------------- |
| **定位**       | 轻量本地便签，非全功能笔记                                            |
| **技术栈**     | Tauri 2 (Rust) + React 19 + TypeScript + Tailwind CSS 4               |
| **开源协议**   | MIT                                                                   |
| **平台支持**   | Windows / macOS / Linux (AppImage)(PR合并但上尚未release)可以自己构建 |
| **安装包大小** | 约 3-7MB                                                              |

> 对比 Electron 动辄 100MB+ 的安装包，Tauri 2 带来的体积优势简直是降维打击。

## 核心功能

### Markdown 编辑与实时预览

花笺支持 **GitHub Flavored Markdown (GFM)** 语法，甚至支持 **KaTeX 数学公式**。编辑和预览模式可以一键切换，写点带公式的笔记完全没压力。

````markdown title="花笺支持的 Markdown 示例"
# 标题

**加粗**、_斜体_、~~删除线~~

- [ ] 待办事项
- [x] 已完成

```python
print("支持代码高亮")
```

$$
\int_{-\infty}^{\infty} e^{-x^2} dx = \sqrt{\pi}
$$
````

### 快捷便签

通过**托盘图标**或**全局快捷键**，随时呼出一个轻便的便签窗口。支持同时开多个小窗，每个窗口独立记东西。

![小窗多开示例](/images/floral-notepaper/小窗多开示例.webp)

> 全局快捷键唤出便签，随手记录，比打开 IDE 写 README.md 方便多了

### 磁贴模式

这个功能是我最喜欢的——**把笔记像磁贴一样钉在桌面上**。设置半透明、始终置顶，放在屏幕角落，随时瞄一眼，比打开任何软件都快。

非常适合：

- 作为**桌面待办清单**，时刻提醒自己今天要干嘛
- 存放**常用命令/代码片段**，复制粘贴一键搞定
- 游戏/看视频时**随手记点东西**，不用切窗口

![AI绘画截图](/images/floral-notepaper/AI绘画截图.webp)

### 导入导出

支持 `.md` 文件的导入和导出。不用担心数据被锁死在这个软件里——你的笔记就是纯文本 Markdown，随时可以迁移到 Obsidian、Typora 或任何其他编辑器。

## 总结

一言以蔽之：**花笺是一个"刚刚好"的桌面便签工具**。不多不少，不重不轻，正好填补了"系统记事本太简陋、Notion 太重"之间的空白。

如果你也在找一个**不折腾、随开随用**的桌面便签，花笺值得一试
