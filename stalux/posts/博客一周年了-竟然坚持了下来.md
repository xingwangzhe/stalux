## 恍惚又是 365 天

> 我回想起了去年这个时候，我还在为博客的第一篇文章而苦恼。如今，博客已经走过了一年，回首过去的 365 天，感慨万千。

### 📅 建站缘由

去年我决定建站的原因很简单：我想有一个属于自己的空间，记录我的学习和生活点滴。那时候，我还没有太多的技术积累，只是觉得建站是一件很酷的事情。第一篇文章就是想办法建立一个博客，可我当时对 web 技术一窍不通，跌跌撞撞，看到一篇文章，稀里糊涂地指引我去 `fork` 它的仓库来建站（我当时对 **GitHub** 更是一窍不通，~~作为计算机专业学生说来还有些惭愧~~）。

我当时还不太懂，只是不明白为什么用 **username.github.io** 作为仓库名就可以建站，而且内容和那个文章的博主一模一样，我都不知道如何去修改内容。于是我又搜索文章，想办法删除那个仓库，又是一番折腾，最后终于删除了。尽管折腾了很长时间，但是还好这些困难对我来说只会更加激励我去做得更好。在此之前，我先恶补了一下现代 web 互联网的知识，接受知识的拷打总是不易，还好通过自我实践和他人经验，我终于成功地建好了自己的博客。

使用的就是最古老悠远，也是现存博客教程中最常用的 `Hexo`，它的配置和使用都非常简单，几乎没有任何门槛。于是我就开始了我的博客之旅。

### 📝 内容创作

刚开始的内容，非常非常的水 💦，好像很多人都是这样，比如说什么 **Markdown 语法教程记录**、**LaTeX 语法教程记录**、**Python 教程**...之类的，今天来看是**不忍直视**的，实在是太羞愧了 💦💦。你现在看到的我的博客只有一百零几篇文章，实际上，算上我删除隐藏的那些水文，足足有 150 多篇文章...

我可以简单列举一下，光看标题就能看出是水文的文章有：

![奇异搞笑水文](https://i.ibb.co/kgStgFMY/2025-06-20-17-05-42.webp)

> 最开始学 HTML、CSS、JavaScript 的水文，现在来看确实够 💦 的

后来才是一些有点质量的文章，比如说最近我在搞 Ubuntu 的文章，我想基本上没人会像我一样闲着没事在 Ubuntu 上研究 [Ubuntu 挂载 Windows 磁盘分区](/posts/3e2e5b68/)、[物理密钥验证](/posts/236a2dce/) 吧（~~物理密钥登录这个资料真不好找，可能是国内真没有用物理密钥在本机上登录的需求吧...~~）。

### 📈 访问量与反馈

截止目前：

:::tip
**本站访客数：12336 人次 | 本站总访问量：24507 次**

应该是比同类站点要少很多的，毕竟我博客被 **Bing** 削了两次，目前收录还没恢复，但索引质量倒是恢复了，看来恢复索引只是时间问题。

![访客与评论](https://i.ibb.co/d06mwBSj/2025-06-20-17-20-24.webp)

互动还可以，这多亏一些博客组织和友链，至少在未被索引的情况下，依然能够有人访问我的博客，还会有人在评论区留言。

### 💻 技能提升

加入 [开往](https://www.travellings.cn/) 后，在群友的拷打下，我倒是学会了熟练使用 Git 和 GitHub，甚至还学会了使用 **GitHub Actions** 来自动部署博客 :)

更进一步了解了互联网的一些知识，比如说 **CDN**、**DNS**、**SSL 证书**等，学会了使用 **Cloudflare**、**Vercel** 等来免费使用 CDN。

乱七八糟前端技术栈都涉猎了一些，比如说 **Vue**、**React**，以及相应的 **Nuxt** 和 **Next**，还有一个最近感觉比较好玩的 **Astro** 框架，它的文档写得非常好，难得有如此详实的中文文档，使用起来也很简单。

### 🎉 未来展望

我的博客之旅才**刚刚开始**！我可不希望**草草结束**，那么未来

希望再稍微精进一点前端技术栈，比如说 Vue 和 Astro，逐步尝试后端技术栈，万一能成为全栈大佬呢 😄？不过还得先坚持下来才可以！

博客已经走过了一年，未来的路还很长，我希望能够继续坚持下去，完成我在 [十年之约](https://www.foreverblog.cn/blog/6304.html) 中的履约证书：[十年之约履约证书](https://www.foreverblog.cn/blog/6304/cert.html)。

正如我在[十年之约](https://www.foreverblog.cn/blog/6304.html)中的寄语那样：

> **十年亦一瞬，一瞬亦十年**
