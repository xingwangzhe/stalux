Welcome to my blog! This is the first post created with the **Stalux** theme.

## About Stalux

Stalux is a modern, high-performance Astro blog theme featuring:

- 🌙 Dark mode with elegant glassmorphism design
- 🔍 Full-text search (Pagefind)
- 📡 RSS & Atom feeds
- 🤖 LLM discovery files (llms.txt)
- 💬 Comment system (Waline)
- 📊 Mermaid diagrams
- 📐 Math formula rendering
- 🖼️ PhotoSwipe lightbox
- 📱 Fully responsive
